# Extraction Decisions Log

This log records disagreements or ambiguous extraction decisions and how they were resolved.

## Format

| Date | Study ID | Variable | Issue | Resolution | Resolved by |
|---|---|---|---|---|---|
| (none yet) | | | | | |

## Rules

- Log any case where two extractors disagree on a variable value.
- - Log any ambiguity in the source text that required judgment.
  - - Resolutions become the authoritative record and should be reflected in `master_extraction_table.csv`.
