# Exclusion Reasons

Use these standardised exclusion reason codes when logging full-text exclusions in `full_text_screening_log.csv`.

## Codes

| Code | Reason |
|---|---|
| E1 | Animal study (no human participants) |
| E2 | Not binaural beat stimulation (monaural beats, isochronic tones only, or different intervention) |
| E3 | No empirical data (theoretical, editorial, review, or commercial report) |
| E4 | Binaural beat effect cannot be isolated (bundled intervention) |
| E5 | No extractable outcome data |
| E6 | Full text not available |
| E7 | Conference abstract only (no full-text data) |
| E8 | Duplicate |
| E9 | Other (specify in notes column) |

## Notes

- Apply only one primary reason per exclusion, even if multiple reasons apply.
- - Record secondary reasons in the notes column of the screening log.
  - - If a study is excluded for E2 but is a review of binaural beats useful for background, retain in `11_notes/reading_queue.md`.
